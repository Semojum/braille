# 역점역 레퍼런스 · `semojum_braille.decoder`

`semojum_braille.decoder` 의 `decode` 와 도구 둘, 입출력 형식, 설정, 모듈 구성.
역점역은 점자 초안을 검토할 때 곁에 두고 보는 **확인용 글**을 만든다. 원문 복원이 아니다. 약자·약어 때문에
여러 묵자가 같은 셀이 되므로 되돌린 글은 근사다.

아래 예는 `[kiwi]` 를 깐 환경에서 돌린 것이다.

| 절 | 내용 |
|---|---|
| 1 | kiwi 가 있을 때와 없을 때 |
| 2 | API 레퍼런스 |
| 3 | 입출력 형식 |
| 4 | 설정(환경 변수) |
| 5 | 모듈 구성(엔진을 고칠 사람용) |
| 6 | 한계와 주의 |

## 1. kiwi 가 있을 때와 없을 때

역점역은 가끔 "이 한글 읽기가 실제 한국어 낱말인가" 를 묻는다. 점자 셀 가운데 상당수가 영어 글자로도, 한글로도
읽히기 때문이다. 영어 교과 책에서 대문자표가 없는 영어 토막은 한글로 잘못 읽히기 쉽다. 이때 한글 읽기가
실제 낱말이면 한글로 두고, 아니면 영어로 되찾는다. 이 물음을 무엇으로 답할지는 설치로 고른다.

| 설치 | 낱말 판정 | 설치 크기 |
|---|---|---:|
| `pip install .` (기본) | 낱말 목록(`decoder/kor_words.json`, 27,790개, 0.38MB) | 약 15MB |
| `pip install ".[kiwi]"` | 형태소 분석기 kiwi(`kiwipiepy`) | 약 233MB |

설치 크기는 리눅스·파이썬 3.10 의 새 가상환경에 깔고 pip·setuptools 를 뺀 값이다(2026-09-29). kiwi 몫 218MB 는
모델 109MB · kiwi 네이티브 확장 41MB · numpy 67MB 다. Windows 에서는 재지 않았다.

**어디서 불리나.** 둘이다. 하나는 `english=True` 로 대문자표가 붙은 토막을 영어로 되찾을 때다. 다른 하나는
로마자 구간이 빈칸 하나를 넘어 쌍점(`⠐⠂`) 앞 낱말까지 이어지는지 가를 때다(`cursory 몹시:` 의 `몹시` 가 한국어인지).
뒤의 것은 `english=False` 여도 드물게 불린다. 점자 코퍼스 18,892쪽에서 판정이 불린 쪽은 2,237쪽이었고, 영어 교과가
아닌 책은 그중 61쪽이었다. 한글만 있는 점자는 어느 쪽이든 결과가 같다.

**실물 세 줄.** 영어 교과 책(점자 코퍼스)의 줄이다. `test/test_kiwi_optional.py` 가 두 환경에서 이 결과를 고정한다.

| 점자 | kiwi | 낱말 목록 | 맞는 읽기 |
|---|---|---|---|
| `⠀⠀⠰⠠⠍⠒⠀⠠⠞⠄⠎⠀⠝⠕⠗⠍⠁⠇⠲⠀⠠⠽⠗⠀⠃⠕⠙⠽` | `  M= 섨어 에이애욱사. 쇠애 b이푀` | `  M= 섨어 에이애욱사. Your b이푀` | 목록(영어 `Your`) |
| `⠴⠞⠕⠲⠀⠘⠍⠨⠻⠇⠐⠮⠀⠠⠠⠎⠜⠀⠚⠑⠪⠐⠥⠀⠦⠴⠡⠕⠕⠎⠑⠴` | `to 부정사를 써야 하므로 "choose”` | 같다 | 둘 다 |
| `⠀⠀⠼⠁⠲⠀⠴⠥⠝⠊⠧⠻⠎⠁⠇⠲⠀⠸⠌⠀⠠⠌⠕⠁⠠⠪⠙⠕⠎` | `  1. universal / 셰익스피어` | `  1. universal / StoaOwdos` | kiwi(`셰익스피어`) |

**코퍼스 전체에서 잰 차이** (점자 코퍼스 94권 18,892쪽, 2026-09-29, AI 71bb1e3 판)

| | kiwi | 낱말 목록 |
|---|---:|---:|
| 한국어를 지킨 줄 | 278 | 196 |
| 영어를 한국어로 잘못 막은 줄 | 147 | 7 |
| 순이득(낱말 판정이 늘 "아니다" 일 때 대비) | +131 | +189 |

- 판정 때문에 달라진 줄을 영어 사전(hunspell en_US)으로 가르고, 쪽마다 앞 세 줄을 셌다.
- 둘이 다르게 읽은 233줄을 낱말 종류 전부 눈으로 가리면 목록이 맞은 줄 143, kiwi 가 맞은 줄 76, 가를 수 없는 줄 14 다.
- 영어 교과 책 12권 가운데 목록이 나은 책은 8권(눈으로 가리면 7권), kiwi 가 나은 책은 3권(4권), 같은 책은 1권이다. 어느 책 하나나 둘을 빼도 합계는 목록 쪽이 낫다. 목록은 영어 교과 책을 한 권도 보지 않고 만들었다.
- 목록이 앞서는 까닭은 영어를 한국어로 잘못 읽지 않아서다. kiwi 는 `your`·`to`·`Emma` 같은 흔한 영어가 한글로 떨어진 조각을 낱말로 받는다.
- 목록이 지는 곳은 목록에 없는 한국어 낱말이다. 놓친 45종은 외래어·고유명사 18(`셔츠`·`샌드위치`·`셰익스피어`), 생활 명사 12(`손녀`·`손님`), 용언 15(낱말 풀이 기본형 `쏟다`·`뽑다`, 해요체 `써요`)다.
- 영어 교과가 아닌 책에서는 둘이 다르게 읽은 줄이 1줄이다.
- 이 값은 AI 71bb1e3 판 역점역으로 쟀다. 이 패키지의 지금 판(AI 8dc7e7b)으로 다시 재지는 않았다.

**고르는 법.** 영어 교과 책의 한국어 풀이(외래어·생활 낱말)를 되도록 한국어로 지키려면 `[kiwi]` 를 깐다. 크기가
중요하면 기본(낱말 목록)으로 둔다. 영어 교과가 아닌 책만 되돌린다면 어느 쪽이든 거의 같다.

- kiwi 는 처음 부를 때 모델을 올리느라 약 2초 걸린다. 낱말 목록은 처음 부를 때 목록 파일을 한 번 읽는다.
- 점역(글자 → 점자)은 어느 쪽도 쓰지 않는다.
- 낱말 목록은 한국어 교재 묵자 1,355쪽(2027 수능특강 비영어 12권)에서 두 번 이상 나오고 두 음절 이상인 한글 덩어리를 모은 것이다. 영어 교재와 정답 점자는 쓰지 않았다. 만드는 법은 `tools/build_word_list.py`.

## 2. API 레퍼런스

공개 계약은 `decode` 하나다(`__all__ = ["decode"]`). 나머지 둘은 도구다. 밑줄(`_`)로 시작하는 이름은 판이 오르면 바뀔 수 있으니 기대지 않는다.

아래 예는 이 준비 코드를 한 번 돌린 뒤의 입출력이다.

```python
from semojum_braille.decoder import decode
```

### 2.1 `decode(braille, *, math=False, english=False) -> str`

점자를 글자로 되돌린다. 줄바꿈은 그대로 두어 줄 수가 입력과 같다.

| 인자 | 타입 | 기본값 | 뜻 | 언제 쓰나 |
|---|---|---|---|---|
| `braille` | `str` | 없음 | 유니코드 점자(U+2800~U+28FF). 줄은 `\n` 으로 잇는다. 빈칸은 `⠀`(U+2800) | 늘 |
| `math` | `bool` | `False` | `True` 면 입력 전체를 수식으로 보고 되돌린다. `False` 면 빈칸 단위 토막마다 수식인지 한글인지 스스로 가른다 | 되돌릴 점자가 **수식 요소 하나**라는 것을 알 때 켠다. 한글과 섞인 본문에서는 끈다 |
| `english` | `bool` | `False` | 영어 교과 책이라는 뜻이다. 한글로 잘못 읽힌 영어 토막을 되찾는다 | 영어 교과 책을 되돌릴 때만 켠다. 다른 책에서 켜면 `ㅅ` 으로 시작하는 한국어 낱말이 영어로 뒤집힐 수 있다 |

- **반환**: 되돌린 글. 줄 수는 입력과 같다. 빈 입력은 `""`.
- **예외**: `braille` 가 문자열이 아니면 `AttributeError`(`decode(None)` → `'NoneType' object has no attribute 'replace'`). 그 밖에는 못 푸는 셀을 `⟨XXXX⟩` 로 남길 뿐 예외를 던지지 않는다.
- **보는 곳**: [regulations.md](regulations.md).

본문, 점역자 주가 든 본문:

```
>>> decode('⠴⠠⠠⠙⠝⠁⠲⠀⠨⠕⠑⠛⠵⠀⠼⠁⠊⠓⠑⠀⠉⠡⠝⠀⠰⠎⠪⠢⠀⠠⠠⠪⠱⠌⠊⠲')
'DNA 지문은 1985년에 처음 쓰였다.'
>>> decode('⠠⠄⠈⠪⠐⠕⠢⠀⠠⠞⠑⠻⠠⠄⠀⠊⠣⠪⠢⠀⠈⠮⠮⠀⠕⠂⠁⠈⠥')
'【점역자주】그림 설명【점역자주】 다음 글을 읽고'
```

`english` 를 켜고 끈 차이(영어 교과서 대화 한 줄):

```
>>> decode('⠀⠀⠰⠠⠺⠒⠀⠠⠓⠪⠄⠎⠀⠭⠀⠛⠕⠬⠂⠀⠠⠇⠊⠁⠍⠦', english=True)
"  W= How's 옥 운이욜 Liam?"
>>> decode('⠀⠀⠰⠠⠺⠒⠀⠠⠓⠪⠄⠎⠀⠭⠀⠛⠕⠬⠂⠀⠠⠇⠊⠁⠍⠦')
'  W= 틋어 옥 운이욜 싸닥우?'
```

`english=True` 는 대문자로 시작하는 영어 낱말(`How's`·`Liam`)을 되찾는다. 가운데의 소문자 영어 약자는 아직 한글로 읽힌다. 영어 본문을 온전히 되돌리는 도구가 아니라 검수용 근사라는 뜻이다.

`math` 를 켜고 끈 차이:

```
>>> decode('⠜⠭', math=True)
'√x'
>>> decode('⠜⠭')
'야옥'
>>> decode('⠭⠔⠽', math=True)
'x-y'
>>> decode('⠭⠔⠽')
'옥-외'
>>> decode('⠼⠃⠌⠼⠁⠢⠭⠘⠼⠃', math=True)
'2분의1+x^2'
>>> decode('⠼⠃⠌⠼⠁⠢⠭⠘⠼⠃')
'2분의1+x^2'
```

앞의 둘은 한글로도 읽히는 셀이라 `math=True` 가 있어야 수식으로 나온다. 셋째처럼 수표가 앞선 식은 켜지 않아도 스스로 수식으로 가른다. 수식은 한국어로 읽는 차례대로 되돌린다(분수는 분모를 먼저 읽어 `2분의1`).

32칸으로 접힌 여러 줄, 빈 입력, 점자가 아닌 글자:

```
>>> decode('⠀⠀⠊⠗⠚⠒⠑⠟⠈⠍⠁⠺⠀⠑⠥⠊⠵⠀⠈⠍⠁⠑⠟⠵⠀⠘⠎⠃⠀⠣⠲⠝\n⠙⠻⠊⠪⠶⠚⠑⠱⠐⠀⠉⠍⠈⠍⠊⠵⠨⠕⠀⠠⠻⠘⠳⠕⠉⠀⠨⠿⠈⠬⠀\n⠠⠊⠗⠑⠛⠝⠀⠰⠣⠘⠳⠘⠔⠨⠕⠀⠣⠉⠕⠚⠒⠊⠲')
'  대한민국의 모든 국민은 법 앞에\n평등하며, 누구든지 성별이나 종교 \n때문에 차별받지 아니한다.'
>>> decode('')
''
>>> decode('abc ⠁')
'⟨0061⟩⟨0062⟩⟨0063⟩ a'
```

접힌 줄은 줄마다 되돌리고 줄 수를 지킨다. 음절 경계에서 접힌 낱말은 줄을 넘어 갈라진 채로 나온다.

### 2.2 `regenerate_syllable_map() -> int` · `semojum_braille.decoder.back`

한글 음절 전부(가~힣)를 `braillify` 로 정방향 점역해 음절 역맵(`braille_syllable_map.json`)을 다시 만든다.

| 인자 | 없음 |
|---|---|

- **반환**: 역맵 항목 수(지금 11,173).
- **쓰는 곳**: **패키지 폴더 안의** `braille_syllable_map.json` 을 덮어쓴다. 쓰기 권한이 없으면 `OSError`.
- **언제 쓰나**: `braillify` 판을 올려 한글 점역 규칙이 바뀌었을 때만. 평소에는 부를 일이 없다.
- 지금 판에서 다시 만들면 실린 파일과 바이트까지 같다(0.1초, 2026-09-29 확인).

### 2.3 `main(argv=None) -> int` · 명령줄

```
python -m semojum_braille.decoder.back 점자            # 되돌린 글을 찍는다
python -m semojum_braille.decoder.back --math 점자     # math=True 로
python -m semojum_braille.decoder.back --file 경로     # 파일(UTF-8)을 되돌린다. --math 와 같이 쓸 때는 --math 를 앞에
python -m semojum_braille.decoder.back --regen         # 2.2
python -m semojum_braille.decoder.back                 # 인자가 없으면 모듈 설명을 찍는다
```

| 인자 | 타입 | 기본값 | 뜻 |
|---|---|---|---|
| `argv` | `list[str] \| None` | `None` | 명령줄 인자. `None` 이면 `sys.argv[1:]` |

- **반환**: 늘 0.
- `english` 를 켜는 옵션과 `--help` 는 없다. `--help` 를 주면 그 글자를 점자로 보고 되돌린다.

```
$ python -m semojum_braille.decoder.back ⠊⠗⠚⠒⠑⠟⠈⠍⠁
대한민국
$ python -m semojum_braille.decoder.back --math ⠼⠃⠌⠼⠁
2분의1
```

`python -m` 으로 부르면 표준오류에 `RuntimeWarning: 'semojum_braille.decoder.back' found in sys.modules …` 한 줄이 찍힌다. 패키지가 이 모듈을 먼저 임포트해서 나는 파이썬 경고이고, 출력에는 영향이 없다.

## 3. 입출력 형식

### 3.1 입력

- 유니코드 점자 블록(U+2800~U+28FF) 글자다. 점자 빈칸은 `⠀`(U+2800)이고, 보통 공백(U+0020)도 빈칸으로 받는다.
- ASCII 점자(BRF)는 받지 않는다. 먼저 유니코드로 바꾼다. 바꿀 때 백틱(`` ` ``)은 빈칸이 아니라 `⠈` 셀이다. 빈칸으로 바꾸면 한글 ㄱ 이 사라진다.
- 줄은 `\n` 으로 잇는다. 32칸으로 접힌 줄이든 접지 않은 논리 줄이든 받는다.
- 파일은 UTF-8 로 읽고 쓴다.

### 3.2 출력

| 점자 | 되돌린 꼴 | 예 |
|---|---|---|
| 한글 음절·약자 | 한글 | `⠊⠗⠚⠒⠑⠟⠈⠍⠁` → `대한민국` |
| 수표 `⠼` + 숫자 | 아라비아 숫자 | `⠼⠁⠊⠓⠑` → `1985` |
| 로마자표 `⠴` … 종료표 `⠲` | 로마자 | `⠴⠠⠠⠙⠝⠁⠲` → `DNA` |
| 점역자 주 표 `⠠⠄` | `【점역자주】` | 2.1 예 |
| 수식 | 한국어로 읽는 차례의 평문 수식 | `⠼⠃⠌⠼⠁` → `2분의1` |
| 못 푸는 셀, 점자가 아닌 글자 | `⟨XXXX⟩`(유니코드 코드 포인트) | `abc` → `⟨0061⟩⟨0062⟩⟨0063⟩` |

- 들여쓰기 빈칸은 공백으로 남는다(2.1 의 `'  대한민국의…'`).
- 원문의 띄어쓰기를 되살리지 않는다. 점자의 빈칸을 그대로 옮긴다.

## 4. 설정 (환경 변수)

기본값이 권하는 값이다. 나머지 값은 판정을 견주어 볼 때 쓴다.

⚠ "임포트" 라고 적은 스위치는 **처음 임포트할 때 한 번 읽는다.** 그 뒤에 바꾸면 안 먹으므로, 프로세스를 띄울 때 환경 변수로 준다.

| 스위치 | 읽는 때 | 기본값 | 뜻 | 언제 바꾸나 |
|---|---|---|---|---|
| `BRAILLE_STYLE` | 임포트 | `book` | 점역 엔진과 같은 이름의 스위치다. 수식 속 `⠈`+글자를 `book` 은 그리스 소문자로, `regulation` 은 로마자로 읽는다(`decode('⠈⠁', math=True)` → `'α'` / `"'a"`) | 점역 엔진을 `regulation` 으로 띄웠다면 같은 값을 준다 |

| `BR_ENG_TOKEN_FLOOR` | 임포트 | `-6.964` | 한글 읽기의 음절 점수가 이 아래면 깨진 한글로 보고 영어 후보에 올린다. 입력 묵자 줄 점수의 1퍼센타일이다 | 되찾기를 더 넓히거나 좁혀 볼 때 |

| `BR_CTX_PAGE_SEED` | 임포트 | `1` | 한 쪽 안에 영어로 확실한 줄(씨앗)이 충분하면 그 쪽의 다른 영어 후보 줄도 영어로 읽는다 | `0` 이면 이웃 줄로만 번진다 |
| `BR_CTX_PAGE_SEED_RATIO` | 임포트 | `0.25` | 그 쪽 본문 줄의 몇 할이 영어여야 쪽 전체를 여나 | 같다 |
| `BR_CTX_KOR_GUARD` | 임포트 | `1` | 영어로 열린 줄이라도 한글 읽기가 한국어다우면 열지 않는다 | `0` 이면 끈다 |
| `BR_CTX_KOR_THRESHOLD` | 임포트 | `-4.5` | 위 판정의 음절 점수 문턱 | 같다 |

## 5. 모듈 구성 (엔진을 고칠 사람용)

모두 `semojum_braille/decoder/` 아래에 있다.

| 파일 | 크기 | 무엇 |
|---|---:|---|
| `__init__.py` | | `decode` 를 내보낸다 |
| `back.py` | 306KB | 역점역 전부. 한글·로마자·숫자·문장 부호·수식을 차례로 되짚는다 |
| `wordlist.py` | | kiwi 가 없을 때의 낱말 판정(1절). 이 레포에만 있다 |
| `kor_words.json` | 384KB | 그 낱말 목록 27,790개(1절) |
| `braille_syllable_map.json` | 245KB | 점자 셀 → 한글 음절 역맵. `braillify` 로 만든다(2.2) |
| `kor_syllable_freq.json` | 16KB | 한글 음절 빈도. 한글 읽기가 한국어다운지 점수를 매긴다. 입력 묵자(교과서 1,361쪽, 음절 101만)에서 만들었고 정답 점자는 쓰지 않았다 |
| `braille_special_rev.json` | 1KB | 특수 기호 역맵 |

- 공개 계약은 `decode` 하나다. `regenerate_syllable_map` · `main` 은 도구다. 그 밖의 이름은 모두 밑줄로 시작하며 계약이 아니다.
- `back.py` 는 점역 모듈(`semojum_braille.encoder`)의 비공개 이름(`_ELEMENTS` · `_TRIG` · translator 내부 표)을 쓴다. 두 모듈은 늘 같은 동기화 커밋에서 함께 옮긴다. 소스를 복사해 넣는다면 `semojum_braille/` 폴더를 통째로 넣는다.
- `back.py` 는 `Semojum/AI` 저장소의 `app/utils/braille_back.py` 를 `tools/sync_from_ai.py` 로 옮긴 것이다. 옮기며 넣는 패치는 둘뿐이다. 역맵 파일이 없을 때 조용히 빈 맵으로 돌지 않고 예외를 내게 하는 것(`SILENT_FIXES`), kiwi 가 없으면 낱말 목록을 보게 하는 것(`KIWI_OPTIONAL`)이다. 고칠 때는 AI 저장소에서 고치고 다시 동기화한다([CONTRIBUTING.md](../CONTRIBUTING.md)).

## 6. 한계와 주의

**못 하는 것**
- 원문을 되살리지 않는다. 약자·약어·기호의 다대일 때문에 되돌린 글은 근사다. 점자가 규정대로인지 **판정하지 않는다.**
- 영어 본문을 온전히 되돌리지 않는다. `english=True` 로도 소문자 영어 약자 일부는 한글로 읽힌다(2.1 예).
- 로마자표 없이 적힌 그리스 문자는 한글로 읽힌다. 그리스 문자 앞 표(`⠨`)가 한글 ㅈ 과 같은 셀이라서다. 이 패키지의 점역은 한글 문장 속 그리스 문자를 로마자표로 감싸 적으므로(`⠴⠨⠁⠲`), 그렇게 적힌 것은 그리스 문자로 되돌아온다. 수식으로 되돌려도(`math=True`) 그리스 문자로 나온다.

```
>>> decode('⠫⠁⠀⠴⠨⠁⠲⠺⠀⠋⠪⠈⠕')   # 이 패키지가 '각 α의 크기' 를 점역한 것
'각 α의 크기'
>>> decode('⠫⠁⠀⠨⠁⠺⠀⠋⠪⠈⠕')     # 로마자표 없이 적은 것
'각 작의 크기'
>>> decode('⠨⠁⠢⠨⠃', math=True)
'α+β'
```
- ASCII 점자(BRF) 입력은 받지 않는다(3.1).

**쓸 때 주의**
- `english=True` 는 영어 교과 책에만 켠다. 다른 책에서 켜면 `ㅅ` 으로 시작하는 한국어 낱말(`손녀`·`습윤` 등)이 영어로 뒤집힐 수 있다.
- 기본 설치(낱말 목록)는 목록에 없는 한국어 낱말(외래어·생활 명사 등)을 영어로 읽는다. 영어 교과 책의 한국어 풀이를 지키려면 `[kiwi]` 를 깐다(1절).
- "임포트" 스위치는 프로세스를 띄울 때 준다(4절).
- `regenerate_syllable_map` 과 `--regen` 은 패키지 폴더 안의 파일을 덮어쓴다(2.2).

**시험하지 않은 것**
- 스레드 안전. 코드에서 본 공유 상태는 이렇다. kiwi 와 음절 빈도표는 처음 부를 때 적재하는데 잠금이 없어, 여러 스레드가 동시에 처음 부르면 두 번 적재될 수 있다(결과는 같다). 동시에 여러 건이 필요하면 프로세스를 여럿 띄운다.
- Windows, 파이썬 3.11 · 3.14.
